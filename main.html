const response = await fetch("https://your-api.onrender.com/v1/execute", {
    method: "POST",
    headers: { 
        "Authorization": "Bearer sk-aura-YOUR_API_KEY",

All API Endpoints

POST /v1/execute Intent-Based AI Router
Automatically routes to text, image, video, or audio engine based on prompt analysis.
POST /v1/chat/completions Text Generation
OpenRouter-powered text generation. Supports GPT, Claude, Llama models. Body: { model, messages }
POST /v1/images/generations Image Generation
Pollinations-powered image generation. Body: { prompt }
POST /v1/video/generations Video Generation
Replicate-powered video generation. Body: { prompt }
POST /v1/audio/speech Audio Generation (TTS)
Google TTS-powered speech synthesis. Body: { input }
POST /v1/files/upload File Upload
Multipart file upload (max 100MB). Uses multer storage.
POST /v1/code/execute Code Execution (VM Sandbox)
Secure VM sandbox for JavaScript execution. Body: { code }
POST /v1/embeddings Text Embeddings
Generates 1536-dimensional embeddings. Body: { input }
POST /v1/moderations Content Moderation
Scans content for policy violations. Body: { input }
POST /api/auth/register User Registration
Register with name, email, password. Triggers OTP email verification.
POST /api/auth/verify Email Verification
Verify email with OTP code. Returns JWT token and user data.
POST /api/auth/login User Login
Authenticate with email and password. Returns JWT token.
POST /api/auth/key-login API Key Login
Login with Aura API key (sk-aura-...). Returns JWT token.
GET /api/auth/session Session Validation
Check if current JWT token is valid. Returns user info and credits.
GET /api/billing/usage Credit Usage
Get current credit balance and daily limit.
POST /api/webhooks/register Register Webhook
Register a webhook URL for event notifications.
